MNIST dataset (784 features)

Logistic Regression

Recognize handwritten digits (0–9)

- Data loading and preprocessing
- Train-test split
- Model training
- Prediction
- Accuracy evaluation
2. Email Spam Classification (Naive Bayes)
Dataset:
Custom text dataset (Spam / Not Spam)
Algorithm:
Multinomial Naive Bayes
Task:
Classify emails/messages as spam or not spam
Steps:
- Text preprocessing using TF-IDF
- Train-test split
- Model training
- Prediction
- Evaluation using accuracy, confusion matrix, classification report

Steps:
- Load dataset
- Train-test split
- Model training
- Prediction
- Performance evaluation
